# Changes
---
- [6eb1651](https://github.com/tathyagarg/harbor/commit/6eb165161deafa4cf68a42206a3686544649dc88): I implemented glyph filling for **basic** glyphs - glyphs with no curves (like `H`, `T`, `E`, etc.). Curved glyphs were giving weird artifacts when filled, so I had to leave them out.
- [f704dab](https://github.com/tathyagarg/harbor/commit/f704dabb33565ee6010b5a6127604acd264e64ec): Turns out the bug with curved glyphs was duplicated vertices after flattening bezier curves. Removing the duplicates fixed the filling issue. So I can now fill glyphs without holes (like `S`, `C`, but not `O`, `A`, etc.)
- [e324354](https://github.com/tathyagarg/harbor/commit/e324354070c6dad58e43f2f26bf7b6e5a58a6704): This was the most annoying bug to track down. I spent probably 2 hours convinced the bug was in my rendering pipline with stencils, but turns out it was because my code wasn't generating triangles for holes because of their winding order. After fixing that, I can now fill glyphs with holes (like `O`, `A`, etc.)
