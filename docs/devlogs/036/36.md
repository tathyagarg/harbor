# Changes
---
- [fe65d19](https://github.com/tathyagarg/harbor/commit/fe65d1928d6a6c6cdc04cafdd7c66a1fbadacaa5): I added some click detection for `<a>` tags. This was pretty simple because of my existing infra.
- [5327aa0](https://github.com/tathyagarg/harbor/commit/5327aa06c57efd8cbb00249a8d92a04c5d8f831e): I added a struct called `Agent` which coordinates all the browser's jobs. This will make it easier to add things like navigation with links later (and a whole lot more, that I'm not thinking about right now!).
- [fc89b22](https://github.com/tathyagarg/harbor/commit/fc89b22c0fe71990a1bc47ed7f71ab6e6bceba3c): Added support for HTTP responses sent with `Transfer-Encoding: chunked`. Spent some time understanding how that even works, but it was a not-so-difficult implementation after that. I only found out this existed because I tried to render `example.com`, which uses chunked encoding.
- [5a95e92](https://github.com/tathyagarg/harbor/commit/5a95e923b29f93dc060f2c55adde309ea92a7fc9): Added some (basic) support for `vh` and `vw` units in CSS. This was kinda annoying because it was a lot of refactoring of my functions to accept the viewport size. It's not even all that rewarding tbh. But whatever, it'll be useful later.
