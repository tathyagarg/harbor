# Changes
---
- [3da9e0a](https://github.com/tathyagarg/harbor/commit/3da9e0ab3ee167987acd010f1dcbd5092ee98488): Made the `TabData` struct store the tab's document and layout objects (well, pointers to them) to allow for reusing layouts when switching between tabs. This was a nice performance improvement.
- [93374d8](https://github.com/tathyagarg/harbor/commit/93374d804fca2ce4b556268d76e344fccd024b47): Made the tab bar render the document's title from it's `<title>` element (and fallback to the url if there is no title). You can now actually tell that there are multiple tabs open.
- [a43551a](https://github.com/tathyagarg/harbor/commit/a43551a5e9008f225bb730f7e9228ee0aded87e8): Played around with the colors in the tab bar. Looks nicer now but the colors are still random so I have to find some actually good colors to use. Also made color of the currently active tab different from the others so you can easily see which tab is active.
- [1c096af](https://github.com/tathyagarg/harbor/commit/1c096afff09317111d2926ff4a611ef1d95f1403): Updated color scheme to be from Catppuccin Mocha (mostly). It's very pretty now!
