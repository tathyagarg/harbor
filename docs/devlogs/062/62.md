# Changes
---
- [87dd979](https://github.com/tathyagarg/harbor/commit/87dd9798521afa38495de7f4aa6167968265a361): Did a big refactor of Environment Records to have their essential methods (`HasBinding`, `CreateMutableBinding`, etc.) are part of a single unified trait. I also fixed some of the algorithms for Global Environment Records which were not simply delegating to their declarative environment records.
- [72c3103](https://github.com/tathyagarg/harbor/commit/72c31038427b038223f899a17626bb874923e056): Started work on generators. Looks like if I want to support parameters to functions I need to implement generators first, so here goes nothing.
- [bd7c26b](https://github.com/tathyagarg/harbor/commit/bd7c26b2e2e6e828df44008215171557cb2077cf): Started working on the function which takes an iterator record and initializes bindings from it - `IteratorBindingInitialization`.
- [5bdb6b8](https://github.com/tathyagarg/harbor/commit/5bdb6b8a23cf76045e5414e082d3b0cda9bfda46): Added a couple functions here and there but important thing is that I've provisionally disabled JS parsing to prevent the browser from crashing when it encounters code it doesn't understand.
- [85ca581](https://github.com/tathyagarg/harbor/commit/85ca581a6fe461f08aa7970c4536f294a88c953f): Big refactor of CSS properties from a single 2000+ line file into a nice big directory with each file corresponding to a CSS property.
- [1ad447a](https://github.com/tathyagarg/harbor/commit/1ad447aed50d422d08f98d489cafa1c169de6b52): Added support for the `cursor` property in CSS. It's pretty basic but after adding it to `<a>` tags, Harbor feels really polished.
