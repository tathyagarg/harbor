# Changes
---
- [19d406f](https://github.com/tathyagarg/harbor/commit/19d406ff1687597ab98d6ffb5dc37c36f8656f86): Refactored the tokenizer to use constants instead of harcoded values for character ascii values. Code is a lot more readable now.
- [550ad1f](https://github.com/tathyagarg/harbor/commit/550ad1f00f2bc82924a17bbbfc823a470f2b071e): Added tokenization of numerics, but only integers for now. Floats next
- [bfce508](https://github.com/tathyagarg/harbor/commit/bfce508c348831fe4cc0d77ec44ba810e930d2bb): Added tokenization of floats as I said I would. Wrote some tests for it as well.
- [0e72d9b](https://github.com/tathyagarg/harbor/commit/0e72d9b88bd02aafd74167f89624df2505e09c6d): Added tokenization of string literals. Both single and double quoted strings are supported. Escape characters are somewhat supported I think? I remember I got ragebaiting trying to implement them, and idk if I ended up doing them or not.
- [425f63c](https://github.com/tathyagarg/harbor/commit/425f63c0fa5abacc74399246b17f42456dbaf755): Added the structs required for parsing the tokens into an AST. There's SO MANY.
- [ff98632](https://github.com/tathyagarg/harbor/commit/ff98632dc7a4493d41f27aad8566ac427960665f): Added the most basic parsing possible for identifiers and numerics. Just parsing into `PrimaryExpression` for now, but it's a start.
- [48a9b11](https://github.com/tathyagarg/harbor/commit/48a9b11c677a4f58490f707edd8103d27ac52474): Copied over the Zig structs into my Rust codebase. This took a while and was pretty tedious. Nothing much interesting, just adapting structs to be Rust-y.
- [4a55934](https://github.com/tathyagarg/harbor/commit/4a5593442bffa2c5fbf2813b776cbd0784b12b8d): Finally called the parser from the Rust side. Added some `Debug` impls to make it easier to see the output. It's definitely working!
